# Previews locais

Capturas de Chromium em 390 × 844 px, com código sintético `123456`.
`pagina-{claro,escuro}-{com-codigo,sem-codigo,invalido,copiado}.png`
cobrem os estados da página.

Executado no navegador: cópia real por teclado, foco visível, texto branco,
botão com 60 px de altura e requisições HTTP sem o fragmento.

Não há prévia do e-mail. As antigas (`email-claro.png` e `email-escuro.png`)
mostravam o botão que o #439 tira e saíram sem substituta: o repositório não tem
gerador de captura, e uma prévia nova pede Chromium. Prévia de e-mail, de qualquer
forma, não substitui teste em Gmail, Outlook ou Apple Mail.
